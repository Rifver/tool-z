# Connect Project to GitHub

## Goal
Enable two-way Git sync between this Lovable project and a GitHub repository so code changes sync automatically.

## Steps

1. Open the Lovable editor for this project.
2. Click the **Plus (+)** menu in the chat input (bottom left).
3. Select **GitHub → Connect project**.
4. Authorize the Lovable GitHub App when prompted.
5. Choose the GitHub account/organization where the repository should live.
6. Click **Create Repository** in Lovable to generate the repo and push the current codebase.

## Outcome
- A new GitHub repository is created with the project code.
- Future edits in Lovable push to GitHub automatically.
- Pushes to GitHub sync back to Lovable.

## Note
This requires user action in the Lovable UI because GitHub authorization must be completed interactively. There is no code change needed in the project itself for basic Git sync.
